# Per-request model-call limit

An optional `workspaceContext.maxDecisionSteps` narrows the existing mode budget. The API and runtime reject values outside integer 1–6. The runtime uses the smaller of this value and the mode allowance, including accounted malformed-response repairs. Omission preserves existing clients. The desktop exposes the control under Agent configuration and binds it into queued-request configuration ownership.

This bounds structured model attempts, not token output or a provider dollar price. Existing admission, conservative reservations, metering, workspace tool policies and independent approvals remain authoritative. It does not make Grok Multi-Agent's aggregate output budget enforceable.

Regression evidence: before implementation the one-call and malformed-repair tests made two calls, and invalid bounds reached admission. Focused runtime, route and desktop tests now pass. Live acceptance remains pending; no paid request was sent during implementation.
