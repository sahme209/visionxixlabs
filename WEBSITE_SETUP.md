## 🚀 Getting Started

### 1. Install Dependencies

```bash
cd visionxixlabs
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to see your website!

### 3. Build for Production

```bash
npm run build
npm start
```

## 📦 Deployment Options

### Option 1: Vercel (Recommended)
1. Push code to GitHub
2. Import project in Vercel
3. Deploy automatically

### Option 2: Netlify
1. Push code to GitHub
2. Connect to Netlify
3. Build command: `npm run build`
4. Publish directory: `.next`

### Option 3: Any Static Host
The site can be exported as static HTML:
```bash
npm run build
# Output will be in .next folder
```

## 🎨 Customization

### Colors
Edit `app/globals.css` to change color scheme:
- Primary colors: Indigo/Purple gradients
- Accent colors: Various gradient combinations

### Content
Edit `app/page.tsx` to update:
- Company description
- App details
- Contact information
- Feature lists

### Images
Add images to `public/` folder and reference them:
```tsx
<Image src="/your-image.jpg" alt="Description" />
```
