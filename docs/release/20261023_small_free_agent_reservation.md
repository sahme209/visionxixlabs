# Bounded Free Agent request reservation

The Free allowance was200 cents but the general request reservation was1000 cents, so an otherwise approved small Agent request could not reach the model. This change admits only a narrowly defined text-only request using the already-approved exact Sonnet5 model. It does not grant any model, tool or account permission.

The complete redacted prompt plus composed system/schema must fit32KiB. Each step independently obtains fresh public Anthropic endpoint pricing, including maximum applicable tier/cache-write/regional premiums. A deliberately conservative estimate prices four input tokens per permitted byte plus8192 wrapper tokens and4096 output tokens, applies the existing1.5 customer billing margin and another1.5 buffer. The full reservation is at least100 cents; if the estimate exceeds100 cents, this path is unavailable. Required exposure is never clipped to available balance. An explicit service reservation override takes precedence.

Only authoritative public Free enrollment can apply the smaller policy, verified in the same serializable transaction that reserves credits. Paid and legacy accounts retain their general reservation and routing. Every new iteration or accounted JSON repair still requires a distinct hold and durable one-use claim. The opaque quote binds actor, organization, correlation, exact redacted payload, model, output limit and expiry. A second opaque one-use dispatch is checked at the final SDK boundary. The wire request is restricted to Anthropic, disables thinking, has no SDK server tools or attachment parts, and allows no SDK retry or optional structured-output expansion. Unknown pricing or changed bindings fail closed.

Cancellation during metadata creates no hold. Cancellation during reservation releases only a definitely unclaimed new hold. A reused hold or uncertain/claimed dispatch is not automatically released or retried. Existing settlement caps customer debits at the reservation and retains provider overruns as platform cost. This is a conservative estimate, not a guaranteed provider-cost cap. Quote/estimate/bounds/pricing-digest evidence is recorded without prompt or schema content.

Verification covers the actual admission/manager/provider chain with inert SDK transport; installed AI SDK plus Gateway HTTP serialization and503 retry behavior; two-step decision flow with two100-cent holds;19 real isolated embedded-PostgreSQL storage cases, including a refused third hold, paid fallback and forged/unenrolled rejection; and one opt-in unauthenticated GET of the current public endpoint metadata. The public metadata check performs no inference, database write or reservation. Full-suite/build/typecheck/review evidence is tracked separately with the exact source commit.

Release limits: generic text generation, other models (including Grok Multi-Agent), larger contexts and other-model cancellation behavior retain their prior path. Signed installers and successful native live Agent acceptance are separate verification. No top-up, plan upgrade, migration replay, credential change, broader tool grant or new Stripe charge is introduced.
