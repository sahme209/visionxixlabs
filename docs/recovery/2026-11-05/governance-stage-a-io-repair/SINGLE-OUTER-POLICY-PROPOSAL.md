## Fixed architecture

`execute_stage_a_packet` retains the sole `/usr/bin/sandbox-exec -p <fixed outer profile> <bound Python> ... --driver-child <packet>`. That process and every fixed descendant inherit the same kernel network/write restrictions. Inside it there are **no** further sandbox-exec invocations: A0's fixed Python offline child; fixed Git reads/archive; pinned Node/npm version and offline ci; four existing Node/Prisma generation commands; fixed producer emitter. The outer profile is constructed and bound before launch. No environment skip key, `skipSandbox`, configurable prefix/runner, caller-supplied command, policy selector, arbitrary callback or runtime/server flag is introduced.

The contained branch is only source-owned Stage A composition, not a claim that a Python object proves sandbox installation. The outer launcher owns policy application; its failure never reaches a ready child. Private command construction cannot grant runtime identity, customer authority, credentials or provider admission.

5. Stage A `_generation`, `_generation_files`, offline child and driver use the **same** captured builder/generation private instance. Internal names can change during the reviewed implementation plan, but the fixed public/private separation and complete nested builder propagation are required. A private generic runner hidden behind a new name would not satisfy this design.

## Policy, environment and bounds

The sole outer profile permits the union already required by the bundle: fresh owned work tree (offline source/dependency/cache copy, generation run/scratch/logs, emission output, private HOME/tmp) plus literal parent outer log. Original source/cache/bound engines/build Node/npm/recipe remain protected against writes. Parent packet/attempt/result stay outside child work and unwriteable. Network remains denied. This union is less phase-specific than separate standalone profiles; it intentionally does not claim per-phase write isolation. All original currentness checks before/after each phase must detect mutation and refuse; no cross-phase changed input is adopted.

Do not add `/dev/null` write permission; retain the reviewed read-only EOF input descriptor and selected private Git stderr spool. Preserve actual inner npm/generation environment construction rather than falsely claiming all commands inherit HOME. Defaults permit reads except explicit denials: no universal secret/read-isolation claim. Descendant post-reap quiescence remains unavailable. No process-group ownership assumption is added.

Keep360-second active driver budget,20-second cleanup margin,390-second outer ceiling; A0≤120/generation≤120/emission≤60 subject to remaining budget. Outer/A0 retain512MiB hard file ceiling for Git archive compatibility; inner generation/emission128MiB; existing64MiB log monitor. No retry, no cleanup-success invention or wider execution lifetime.
