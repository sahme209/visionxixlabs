## Selected finite compiler change

1. Keep actual private authentication/session/role/commercial code unchanged. Exact compiler alias `next/server$` selects the pinned actual `node_modules/next/dist/server/web/spec-extension/request.js` class, rather than eagerly importing unrelated ImageResponse/after/connection exports from `next/server.js`. Exact `zod$` selects pinned `zod/index.js`, keeping one coherent bundled Zod instance. No replacement request/auth implementation is introduced.
2. New compiler-only policy module plus frozen JSON source/package closure. Bind source38, package95, selected Next/Zod package metadata and the compiler policy/manifest through source archive/input observations. Before compiler construction, validate all current files/hash/selected versions. The actual future stage comes from the same source archive and fresh SRI-verified offline dependencies.
3. The emitter external callback retains fixed absolute `@prisma/client` mapping and builtin-only externals. It permits bundling ONLY literal `zod`, `next/server`, and `next/dist/compiled/@edge-runtime/cookies`; relative and owned `@/` edges resolve normally but the actual resolved resource must belong to the frozen source/package file set. Unknown bare requests refuse. No host module fallback or arbitrary package prefix allow is added.
4. Parser import, re-export, CommonJS require and dynamic-import hooks reject any runtime `next/server` import other than named NextRequest (including namespace/default/other names). Resolved-module hooks independently reject any file outside the frozen source/package set; legacy global db/vault/session/token refusals remain. A changed source graph requires a fresh deliberate source/closure review, not automatic allowlist expansion.
5. Keep the raw preimport full readonly-package verification banner, administrative entry, fixed output path and final0600 quarantine. No producer invocation, native resource operation, permission, issuer identity or action authority is added.
