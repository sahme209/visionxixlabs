Actual mounted Agent search handled Enter/Escape without composition checks. The early guard now ignores both during native isComposing or legacy keyCode229. It does not consume the event, close search, submit an intermediate title query or send an Agent message. Existing non-composition Enter (with its existing nonempty/not-busy predicate), Escape and button behavior stay intact.

First test diagnostic used the wrong query-parameter name; preserved separately, not acceptance evidence.
