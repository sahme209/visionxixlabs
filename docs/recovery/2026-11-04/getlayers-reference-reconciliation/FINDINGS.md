# GetLayers: bounded public reference evaluation

The user's new B2 master-plan instruction explicitly requests GetLayers reference evaluation. Four unique official public text pages were reviewed under that scope. No account, MCP connection, installation, asset/code import, purchase, agreement or deployment occurred. This is not interactive browser research or visual acceptance; the work-browser restriction remains in force.

- [Homepage](https://www.getlayers.ai/): the vendor describes templates, hero sections, gradients, scenes, interactive backgrounds, AI tools and Figma workflows. Its FAQ describes commercial client work on paid plans and free materials as try/adapt content. Actual media and interactions were not evaluated; vendor performance scores are not Axiom measurements.
- [Pricing](https://www.getlayers.ai/pricing): the FAQ describes commercial licensing even for free layers, with adaptation encouraged. That wording differs from the homepage's paid-plan answer. No exact asset or commercial use has been cleared. Library-copying and plan fair-use constraints require review before any future adoption; no bulk extraction was performed.
- [MCP](https://www.getlayers.ai/mcp): the vendor states Full Stack Lifetime access and sign-in/approval are required. Claimed Codex/client compatibility is not an Axiom qualification. No connector command was executed, account connected or remote server contacted.
- [Terms](https://www.getlayers.ai/terms-of-use): observed account/fair-use provisions do not resolve the conflicting license wording. A later cached section response was truncated and provides no additional usable evidence. Do not infer a legal clearance or unrestricted redistribution right.

## Decision

Reference-only, not adopted. Keep existing Axiom tokens/framework and build original governance storytelling. A future isolated hero/workflow pilot must have authentic states, provenance and exact asset/output license clearance before integration. Prefer simple CSS and justified motion; measure reduced-motion, keyboard, responsive and performance behavior under B6. Do not copy template identity or inherit vendor quality claims. Paid MCP access is unnecessary for this reference stage and remains unauthorized. Prompt Motion is still a separate unvisited reference.
