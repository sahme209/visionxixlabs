## Interfaces and files

1. nativeTime/record.ts: readonly TimePublication {version:1,layout:'clockbound-v2',sourceGeneration:string,publication:bigint,asOfNs:bigint,voidAfterNs:bigint,boundNs:bigint,driftPpb:bigint,status:'synchronized'|'unknown'|'disrupted'|'free-running',disruptionMarker:bigint,disruptionSupported:boolean}; encodeTimePublication(value):Uint8Array; decodeTimePublication(bytes):Readonly<TimePublication>.
Wire is exactly12 LF-terminated ASCII lines: AXIOM_TIME_V1,clockbound-v2,generation,publication,asOf,voidAfter,bound,drift,status,marker,0-or-1,END. Generation /^[A-Za-z0-9_-]{1,128}$/; integers canonical unsigned decimal; <=4096bytes; time/bound<=2^63-1; publication1..2^64-1; marker0..2^64-1; drift<1e9; voidAfter>asOf. No JSON duplicate keys or Rust ABI bytes.
2. nativeTime/publisher.ts: synchronous createTimePublisher(generation,ports) with publish(value:Omit<TimePublication,'version'|'sourceGeneration'|'publication'>):void. Ports assertCurrent():void; createStage(bytes,name):opaque object; finishStage(stage):void; replaceCurrent(stage):void; delegate(value):void; fatal():never. Counter consumed before staging, no reuse/wrap; every error permanently fails generation then calls fatal, never delegate/continue; snapshots captured and immutable.
3. nativeTime/interval.ts: export NanoInterval={low:bigint,high:bigint}; NativeTimeSample={realtimeNs:bigint,p0:NanoInterval,p1:NanoInterval,p2:NanoInterval}; TimePremises={asOf:NanoInterval,voidAfter:NanoInterval,maxAgeNs:bigint,lambdaMin:{numerator:bigint,denominator:bigint},lambdaMax:same}; encloseTimePublication(publication,sample,premises):Readonly<{earliest:number,latest:number}>. Exact formula from design, positive ordered rates, safe limits, strict freshness/expiry, synchronized+disruption support only. Pure caller inputs are NOT native qualification.

Worker capture carries record bytes+NativeTimeSample+opaque held source identity; native context checks before/after capture and final sample currentness. Require same generation/identity/disruption, no cache/retry or Date fallback. Construct actual createNativeCustodianPorts/createOperationalEcsSdkTransport/createOperationalWorkloadRunner with same source instance. Preserve unregistered default workloadHTTP503. Synthetic positive tests must be explicitly synthetic, not a public profile issuer.
5. packages/verified-issuer-runtime/linux/time_publication.c/.h, time_publication_adapter.rs: dormant actual fixed openat/O_EXCL/O_NOFOLLOW/write/sync/read-only/close/rename directory protocol and bounded consumer clock/read/identity checks, plus Rust authoritative V2 ShmWrite hook using inspected getters.
