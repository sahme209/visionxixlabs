# Node25 browser-test storage interference

The broad suite reported window.localStorage.clear is not a function. Current local Node is25.2.1; direct node inspection reports global localStorage as an object whose clear member is undefined, with a warning that no valid backing-file path was provided. Vitest aliases window to its populated global environment. This is not proof that Axiom's real browser localStorage is broken.

Controlled reproduction: passing --no-experimental-webstorage only to the parent node CLI left both browser suites failing17 cases, because that invocation did not configure the workers equivalently. Setting NODE_OPTIONS=--no-experimental-webstorage for the process and its child workers made those same17 cases pass. A second targeted run applied the same environment to the eight other suites whose recorded failure groups named the same localStorage error;282 checks passed.
