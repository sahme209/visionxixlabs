## Finding and next unit

Actual private DB/vault/App read authentication/session APIs exist, but the actual merge composition cannot yet capture all of them. In particular `createPrivateGithubAppAuth` returns read-profile token methods, not `resolveReleaseInstallationToken`, `readReleaseInstallationEligibility` or their matching proof consumer. Passing its current return value to merge would omit real write minting. Merely supplying a private repo to the existing coordinator also leaves legacy session, App and transitive default-client imports.

The next implementable unit is **extract the existing release authentication implementation into an explicitly bound instance core**, preserving legacy wrappers, then expose the same methods from the private App auth instance. This changes the private API boundary from read authentication to actual release-purpose mint/eligibility and therefore requires explicit approval before implementation. It does not authorize executing those methods against a provider. The remaining finite dependency threading below is the follow-on local composition unit; neither unit enables an issuer or installs a private bootstrap.

## Transitive imports that supplying a repo does not fix

`createGovernanceRequestService(request,repo,scope,isEnabled)` eagerly composes `createGovernanceRequestAuthority`, execution policy service, GitHub/AWS collections and imports deployment authority. `requestAuthority.ts:4`, `enrollmentDrainAuthority.ts:4` and `releaseDeploymentAuthority.ts:4` import the legacy resolver. The resolver imports `lib/db.ts`, legacy token/session, personal-membership repair and commercial entitlement readers; the latter reaches global `tenantBillingStore`. This is real default-resource import reachability even for merge operations that never call deployment methods.

Required narrow extraction: a shared dependency-only Governance request-service implementation whose legacy wrapper constructs its current dependencies, while the private composition supplies real authority, execution-policy, evidence/document/revision/baseline/drift and source readers. Preserve the original implementations of methods used by this graph: `hasAnyEnrollment`, `readScopeEnrollment`, `readActiveEvidence`, `readScopeEnrollmentLocked`, `assertMergeApprovalBaseline`, `readAnyEnrollmentLocked`, `readExecutionCoverage`, and `executionPolicies.readAuthority` (including its locked form). Do not implement these as ready/allowed stubs or remove current source revalidation.

`githubCollectionRequestService.ts:18` constructs `createGithubGovernanceDiscovery`; that discovery accepts `resolveToken`/fetch ports but its wrapper does not pass them. It also imports legacy release auth and `parseRepositoryFullName` from `resolveTenantScopedToken.ts`, which eagerly imports global Prisma (`:18`) and legacy auth. The same parser import leaks into merge token/credential/topology dependencies. Extract this existing pure parser/type into a dependency-free module and re-export it for legacy compatibility; thread private release-token/fetch/time through the collection wrapper. Merely passing resolveToken while retaining the legacy value import is insufficient for a closed emitted graph.

AWS collection is reachable through the full service import; its actual discovery calls `withTenantAwsConnection`/`readVerifiedGovernanceMetadata`, whose closure reaches legacy vault and environment configuration. This direct GitHub merge unit must remove unused AWS/deployment construction from the merge-specific import closure by extracting the same merge-needed service operations with explicit source-reader selection. It must retain genuine current GitHub/document evidence implementations, and refuse evidence outside that narrowly reviewed supported source set without claiming AWS coverage. Supporting AWS evidence later requires the real AWS resource adapters; a dummy AWS allowed/readiness result is forbidden. This is an explicit scope restriction requiring review, not implicit equivalence to the full service.

Commercial entitlement remains a required actual dependency of `createPrivateRequestDesktopSessionResolver` (`desktopSessionResolverCore.ts:49–56`), not supplied by private DB/token alone.
