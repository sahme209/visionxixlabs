## Proposed implementation unit

No dependency install/lockfile change or native import/run in these tests. Real use requires separately reviewed exact worker/package/native-library/platform qualification and protected launch/resource evidence; a caller boolean/hash cannot qualify it.

- Application limits: original bytes1..2MiB; PNG/JPEG only; dimension1..4096 each; at most4,194,304 pixels; raw uint8 RGBA at most16MiB. These are application restrictions, not vendor maxima. Reject unsupported color/depth/profile/animation rather than silently convert the artifact uploaded to the provider.
- Strict bounded format-envelope inspection before decoder: exact PNG signature and complete bounded chunk framing with IHDR first, IDAT present, IEND final; reject animation chunks, trailing bytes and unsupported structures. JPEG exact SOI/EOI and bounded marker/scan framing; reject multiple-image/container/unsupported segments as required by the qualified format profile. This is structural rejection, never full-decode acceptance.
- Fixed buffer input only, no paths/URLs/streams/caller options. Set failOn warning, unlimited false, pixel/channel bounds and sequential read; constrain native loaders to the qualified format profile. Check actual metadata format/dimensions/pages/depth against structure/MIME. Evaluate the entire raster to uint8 RGBA and verify exact width*height*4 length; header-only success cannot pass. Clear raster and copied input in finally; return only MIME/dimensions/exact profile digest, never decoded pixels or raw errors. Original bytes remain unchanged for the separate exact-byte upload.

Worker must have independently qualified memory/CPU/filesystem/network/resource isolation; Node heap limits alone do not bound native memory. Exact numeric OS limits and launcher must be reviewed against actual supported host before a real profile is possible.
- Any loader failure, mismatch, unsupported metadata, truncated input, worker exit, abort, deadline or cleanup uncertainty refuses with one fixed category; no renderer/send follows. The protected qualification binds algorithm/source/dependencies/native binary/platform/launcher/limits and adversarial corpus; missing/stale evidence refuses.
