## Finite actual cases

1. **Joined success:** actual private hold → record bytes/BigInt identity → worker FD bootstrap and exec → one actual capture → frame/EOF plus normal owned reap → raw observation with fresh parent P2 → explicit release. Require original R/P0/P1 retained; P0≤P1≤workerP2≤parentP2; identity/bytes/pub/marker match; completed and repeated terminate resolve after known reap without signalling another PID. Require release success AND an exact test-only native close observation: the original held descriptor close was attempted once, returned0, and the hold transitioned closed without close_unknown after all operation references drained. Do not infer this solely from a JS promise, unlink success, or an FD number later returning EBADF (which could be recycled). Values remain raw; never feed an accepted premise or advertise a qualified source.
2. **Replacement:** after acquiring an original hold, atomically rename a separately created immutable publication over the fixed current name; `assertResourceCurrent` and `start` result must refuse as applicable. Do not reopen and silently substitute the new publication under the old hold. Explicitly release the original. A fresh separate parent/case may observe the new generation; no restart/retry of this failed observation.
3. **Deterministic cancellation/cleanup:** the test-only initializer creates a separate cancellation-case private parent with the exact fixed stall-fault ELF opened read-only and verified by descriptor/hash, never a JS-selected path or FD. That ELF writes a single fixed nonsecret readiness marker through its inherited fixed synthetic directory FD, closes the marker, then stalls in `poll(NULL,0,-1)` with no normal-exit path. The marker resides only in this fresh cancellation-case lab directory and is absent before launch. A bounded test-only native observer verifies the exact owned marker after exec before JS calls terminate. If readiness cannot be established before a fixed early cutoff, stop this case as failed; do not call deadline cancellation a successful explicit-cancel test. Invoke terminate explicitly before the 500ms native deadline and preserve its idempotence. The SAME owned-pidfd wait result must report `CLD_KILLED` and `SIGKILL`, with the native cancellation-request timestamp preceding the native operation deadline. Require known reap and quiescence before completed, plus explicit release after cleanup; a completed promise, exit70, natural exit or parent timeout alone does not pass this case. One fixed fault ELF, one invocation, no retry.
4. **Refusals:** malformed/unknown foreign plain JS hold and a genuine hold from the second private parent cannot be started/released/observed by the first parent. An `unknown` publication is structurally readable raw data only; the test must not equate successful raw capture with usable time or admitted execution. Never import an accepted-policy mint to make this case pass.

Each case runs once. Source/mock tests first establish harness/result-validation guards; they do not prove C behavior. Keep exact fixed result rows/case labels and bounded timestamps/counts, not filesystem paths or environment dumps.
