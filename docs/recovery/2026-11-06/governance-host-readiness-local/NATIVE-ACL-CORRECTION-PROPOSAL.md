Propose one internal shared header `packages/verified-issuer-runtime/native/protected_acl_empty.h`, included by the seven affected files. It provides one finite Boolean emptiness predicate for an already acquired ACL handle, with explicit ownership/free semantics. Preserve each caller's existing `acl_get_file` versus `acl_get_fd_np` retrieval and all canonical path, descriptor, owner/mode/link, source/currentness and journal checks. It makes no assumption about binary layout or entry-return conventions. Mismatch means refusal, never absence. Every missing handle, allocation failure, invalid/oversized size, copy error/short result or cleanup failure refuses. Free all owned buffers/ACLs on every path; do not close the caller's file descriptor. No text/ACE names/UUIDs are formatted, persisted or logged. This follows the inspector's reviewed bounded empty-ACL proof without exposing its host-inspection entrypoint or creating shared authority. Exact signatures/ownership and SDK source bindings require independent implementation review.
