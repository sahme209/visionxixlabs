## Playback contract

Initial render is static, including SSR. Play or Replay starts a single 60ms clock for typing, cursor and progress. Manual steps pause, review stops automatic progression, and all decisions are explicitly samples. Changing story or context resets both progression and decisions. Previous/next and chapter buttons remain available with reduced motion. Arrow/Home/End shortcuts apply only within playback controls; native selects retain their keys. Live reduced-motion changes stop playback. IntersectionObserver and document visibility stop timers offscreen and in background tabs; returning resumes elapsed state without a catch-up jump. Cleanup removes listeners and timers.

The terminal-like panel is labeled bounded check output and scripted; it has no input or command execution. The actual native implementation in desktop/src-tauri/src/verification.rs clears inherited environment variables, then supplies PATH, HOME, CI and NO_COLOR. This does not isolate the filesystem or remove stored credentials accessible to the operator account. It uses a 5-minute timeout and independent 1,000,000-byte caps on stdout and stderr; the combined returned text can exceed 1 MB. The demo describes these separate limits and retains explicit approval. No native code is changed. GitHub review grants no merge or cloud action. Terraform ends held. The general terminal, local Agent execution, native acceptance, production sign-in and cloud end-to-end limits stay visible. Example filenames and code are invented sample content, not claims of customer evidence. Source file mapping is documented here, not placed in marketing UI.
