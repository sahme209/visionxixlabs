# ChatGPT public website audit — in progress

Observed November 1, 2026 in the visible browser. The official overview address redirected to https://chatgpt.com/overview/. No private chats, account credentials or customer data were used.

- Overview: a prominent plain-language product proposition, two main CTAs, and three hero modes. Clicked chat/work/code; each selection changed its pressed state and matching product illustration. The hero is a visual explanation, not a live account action.
- Features menu: inspected grouped destinations; Learn menu separates audiences, inspiration and task examples. Distinct Business, Pricing, Download and Codex destinations remain clear.
- Plugins page: inspected outcome-led explanation, permissions/admin controls, illustrated workflow tabs, step-by-step setup and separate build-your-own/documentation paths. No plugin connection, installation or grant was performed. Tab and setup-disclosure behavior is still being checked.
- Business/pricing/download initial navigation briefly returned verification/loading pages. Do not mark those targets inspected from an empty initial outline; no challenge bypass or new login occurred. Revisit with normal browser state and verify loaded content before recording acceptance.

Axiom implications: use one clear governance/deployment purpose; let visitors switch between bounded release, Bot and evidence stories; pair each story with real labeled product captures. Separate product explanation, connector capabilities/permissions and actionable documentation. An integration logo is not proof of supported or connected capability. Keep customer costs, support and security boundaries discoverable without copying another product's claims or trade dress.

Pending: all feature-demo tabs/step disclosures, full business/pricing/download contents and unique controls; representative feature/detail page, privacy/help destinations, responsive/accessibility checks. Codex is a separate later reference in the requested sequence. Authentication, purchases and outbound forms are not part of this public design audit.

| Web setup radio | Selected state and URL changed to ?setup=web; visible instructions changed to the web path instead of keeping irrelevant desktop steps. | Use a stable shareable platform choice and show the appropriate prerequisites rather than one oversized guide. |
