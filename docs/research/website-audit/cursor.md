## Demonstration distinctions

The homepage's interactive rendered UI is not the same thing as its “Request a demo” sales link. Axiom needs both an immediate self-guided product demonstration and a clear human-contact path if offered. Record actual Axiom workflows with synthetic data; do not copy Cursor's media, testimonials, certification claims or customer logos. Any simulation must be labeled; controls in a simulation must never imply provider writes.

## Website and documentation acceptance decisions to carry forward

1. Purpose before detail; one primary next action and a secondary learning path.
2. Authentic visual proof; informative captions/transcripts and useful still frames.
3. Task-oriented documentation plus stable control/reference coverage.
4. Search includes permissions, expiry, uncertain outcome and recovery—not only feature names.
5. Show prerequisites, expected outcomes and limitations next to instructions.
6. Preserve Axiom identity, genuine reviews and truthful supported/preview/planned states.
