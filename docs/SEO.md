# SEO setup

## What’s in place

- **Root metadata** (layout): default title, description, keywords, Open Graph, Twitter cards, canonical, `metadataBase`, `robots`, `viewport` (themeColor).
- **Per-page metadata**: unique titles and descriptions; canonical URLs and Open Graph where relevant.
- **Structured data (JSON-LD)**: Organization and WebSite on every page.
- **robots.txt**: `/robots.txt` generated by `app/robots.ts` – allows crawlers, disallows `/internal/` and `/api/`, links to sitemap.
- **Sitemap**: `/sitemap.xml` generated by `app/sitemap.ts` – all public pages including dynamic cloud solution routes.
- **Web app manifest**: `/manifest.webmanifest` – name, icons, theme color for mobile and PWA.

## Target keywords (in `lib/seo.ts`)

Primary: cloud engineering, AWS consulting, Azure consulting, GCP consulting, multi-cloud, Infrastructure as Code, CI/CD, DevOps, FinOps, cloud cost optimization, landing zone.

Secondary: cloud migration, Kubernetes, Terraform, GitHub Actions, Octopus Deploy, AI solutions, enterprise cloud, cloud security, SRE, observability.

## Indexing

1. **Google Search Console**: Add property for `https://visionxixlabs.com`, verify ownership, then submit sitemap: `https://visionxixlabs.com/sitemap.xml`.
2. **Bing Webmaster Tools**: Add site and submit the same sitemap URL.
3. After deploy, request indexing for the homepage and main sections (Cloud Solutions, AI Solutions, Contact) if you want faster discovery.

## Backlinks and press

- **`/press`** – Press & Media page for backlink acquisition. Provides canonical URL (`https://visionxixlabs.com`), suggested anchor text, logo usage, and a one-line description. Link is in the footer under Company. Use this URL when requesting or suggesting backlinks from partners, directories, or press.
