# Internal source-guide index

**Internal authoring queue — not customer documentation.** These guides describe particular source snapshots. Listing a guide does not establish current access, shipped behavior, genuine editorial approval, accepted media or permission to execute an action. A source hash is provenance, not authority. Follow the [full master checklist](../axiom-master-action-plan.md) for remaining acceptance.

Proposed evaluation cases are not executed retrieval results. None of this index approves a catalog, ingests customer data or activates a support assistant.

## Advance a draft safely

1. Check its exact source/version and actual mounted controls before relying on it. Preserve historical records; append a new revision when behavior changes.
2. Capture authentic, redacted media and exercise the supported release, including errors, uncertainty, keyboard access and recovery.
3. Obtain genuine editorial/release decisions and separately verify customer/public eligibility. Metadata alone cannot make those decisions.
4. Update the coverage queue and exact bindings. Keep missing controls and unaccepted states open; do not infer whole-app coverage from this index.

Home, Agent, Releases, Batches, full Settings and the remaining nested workflows still need their full source-to-control, media and release acceptance under B4. Every linked draft also retains its own limitations. No native walkthrough, current connection health, provider action or publication occurred while creating this index.
