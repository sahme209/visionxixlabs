# New TEST credit policy decisions

For newly created TEST subscriptions only, when should included AI credits reset? This does not authorize live billing or change existing customers.

Answer: Subscription anniversary each month; no rollover (Recommended)

For a new TEST customer upgrading from Free, how should prior Free usage affect the first paid allowance? Purchased credits must retain their existing balance in either case.

Answer: Full paid allowance; prior Free usage stays in its original bucket (Recommended)
