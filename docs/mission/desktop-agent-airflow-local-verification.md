# Desktop Agent, Airflow and reliability increment

Local candidate only. The accepted web cockpit, production database/configuration, model/tool grants, payments and published installers are unchanged. This increment does not establish complete Cursor parity or successful live AI automation.

## Implemented

- Automation Agent with three tenant-bound read-only tools: list DAGs, observe runs and inspect task instances. Live paired-session, accepted membership, tool allowlist and current connection checks apply; observations are discarded on revocation/rotation. No model-controlled URLs, credentials, logs, XCom, retries, triggers or task-state changes. Results cover at most 20 entries and explicitly mark incomplete first-page coverage.
- Airflow DAG/run Investigate hands the exact selection into an unsent Inspect-mode draft. The Automation profile narrows even DeepOps to its approved read tools. It does not grant identity permissions or automatically start inference.
- Airflow read states distinguish unavailable catalogs/history from empty results. Refresh disables stale actions while preserving automation drafts. Optional 15-second run watching stops outside the visible DAG view. Manual runs require an exact-DAG confirmation; service execution authority remains separate. Unknown provider failures show bounded, uncertain-outcome guidance instead of raw diagnostics or automatic replay.
- Agent replies render safe Markdown, lists, tables and copyable code. Raw HTML and remote images do not render; only explicit safe HTTPS links open externally. Copy never executes code. Large legacy replies fall back to plain text.
- Model search includes actual catalog IDs; All/Approved filters do not mutate policy. The catalog renders bounded 50-row pages with Previous/Next, while search includes every row. This fixes a large-catalog native accessibility failure. Grok remains behind existing Gateway catalog, workspace model approval, identity, billing and metering gates. No new provider or model was enabled.
- Saved-chat title search and stable seek pagination retain caller ownership and drafts. Older results open only on explicit selection. Late results after edited queries or changed sessions are ignored. An older service without the search capability returns an honest update-required state. Titles only; this is not full transcript search or snapshot-isolated history.
- Last local repository/worktree restores only within the verified account/workspace and fresh native inventory. Foreign/stale paths are not trusted; an unavailable managed checkout falls back to its known primary root. Only navigation paths are stored, not credentials or file content.
- Shared confirmation dialogs trap keyboard focus, cancel safely, and restore their opener. Settings prevents overlapping preference clicks and serializes native writes across view remounts; subsequent reads wait for writes. Saved feedback follows confirmed storage. An uncertain save disables further preference edits until Settings is reopened and never exposes raw storage errors.
